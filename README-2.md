# Supermarket Sales Analysis

## Project Overview
This project analyzes supermarket sales data to identify useful business insights about products, branches, categories, customers, payment methods, and ratings.

## Files
- `supermarket_sales_analysis.py` - Main Python analysis script
- `requirements.txt` - Required Python libraries
- `supermarket_sales_analysis_report.pdf` - Project report
- `supermarket_sales.csv` - Input dataset (place this file in the same folder)

## Technologies Used
- Python
- Pandas
- Matplotlib

## How to Run

1. Install Python 3.9 or above.
2. Place `supermarket_sales.csv` in the project folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the project:

```bash
python supermarket_sales_analysis.py
```

## Output
The script creates a folder named `supermarket_analysis_output` containing:
- Cleaned dataset
- Summary CSV files
- Product, branch, category, payment, and customer charts
- Overall analysis summary

## Key Findings
The project summary reports:
- Cheese generated the highest product sales.
- Branch C (Mumbai) recorded the highest branch sales.
- Beverages generated the highest category sales.
- UPI was the most-used payment method.
- Normal customers had a slightly higher average transaction value than Members.
- Average customer rating was approximately 3.99 out of 5.
